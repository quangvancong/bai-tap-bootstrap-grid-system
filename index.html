Giới thiệu

Chào mừng bạn đến với trang web thực hành Bootstrap Grid System. Đây là bài tập giúp làm quen với cách xây dựng bố cục website responsive.

1. Bootstrap là gì?

Bootstrap là một framework CSS hỗ trợ xây dựng giao diện website nhanh chóng. Framework cung cấp các thành phần như Navbar, Button, Card và nhiều công cụ bố cục khác.

2. Bootstrap Grid System

Grid System chia bố cục thành 12 cột. Lớp container giới hạn chiều rộng nội dung, row tạo hàng và các lớp col-* xác định chiều rộng từng cột.

3. Thiết kế Responsive

Responsive giúp website tự điều chỉnh bố cục theo kích thước màn hình. Trong bài tập này, nội dung chính và sidebar nằm cạnh nhau trên màn hình lớn, nhưng chuyển thành hai hàng trên màn hình nhỏ.

Lưu ý: Hãy thay đổi kích thước trình duyệt để kiểm tra bố cục của trang web.
